#  Arch Linux Hyprland Dotfiles

Customized *Hyprland* setup on Arch Linux, inspired by [@JaKooLit](https://github.com/JaKooLit)’s *Hyprland* configs.
This repo contains tweaks built on top of his base.

---

##  Setup

- **Distro:** Arch Linux
- **WM:** Hyprland
- **Terminal:** Kitty
- **Shell:** Zsh + Oh My Zsh
- **Bar:** Waybar
- **Launcher:** Rofi <!-- - **Notifications:** Mako -->
- **File Manager:** Thunar
- **Editor:** VS Codium (Monokai)
- **Compositor Effects:** Built into Hyprland (blur, shadows, animations)
